# MyFirstGame

这是一个基于 .NET 10 的小游戏仓库，目前包含两个可运行的 Web 小游戏项目。

小学二年级学生在玩通关Untitled Goose后，自己用AI生成的游戏。

## 项目总结

- **MyFirstGame**：浏览器版贪吃蛇（Snake）小游戏，支持方向键控制、开始按钮和分数显示。
- **大鹅模拟器**：以“捣蛋大鹅”为主题的潜行闯关游戏，包含多关卡、任务互动（E 键）和敌人巡逻机制。

## 技术栈

- **.NET 10**
- **ASP.NET Core Minimal API**（提供静态文件与健康检查接口）
- **HTML/CSS/JavaScript + Canvas**（前端渲染与交互）

## 运行说明

可分别进入以下项目目录执行 `dotnet run`：

- `MyFirstGame/MyFirstGame.csproj`
- `大鹅模拟器/大鹅模拟器.csproj`
